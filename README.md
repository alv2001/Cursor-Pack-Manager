# 光标套装管理器

一个 Windows 小工具，用来把成套的鼠标指针一键换上去，不用在「控制面板 → 鼠标 → 指针」里一个个状态点「浏览」。

里面已经自带一套示例：吉伊鼠标指针第一弹（17 种状态全都有）。

## 一、怎么打开

1. 把「光标套装管理器.exe」放到任意位置（桌面、D 盘都可以），不需要安装，不需要管理员权限。
2. 双击它。第一次打开要等 3~5 秒，屏幕上看不到反应是正常的（程序要先把自己解压到临时目录），不是卡死。
3. 弹出标题为「光标套装管理器」的独立窗口，就打开了。

如果出现「Windows 已保护你的电脑」：
- 点「更多信息」→ 点「仍要运行」。
- 这是因为程序没有购买代码签名证书，不是病毒。
- 360、火绒等软件如果提示可疑，选择「允许」或加入信任即可。

如果提示缺少 Microsoft Edge WebView2：
- 点「是」会打开官方下载页，装好后再打开本程序就行。
- （Win11 和大部分 Win10 已经自带，一般不会遇到）

## 二、怎么换光标

打开后左边是套列表，右边是这套的 17 个状态。

- 点右边蓝色的「启动这套」→ 系统光标立刻换成这一套。
- 点「停止」→ 恢复成你原来的光标设置。

右上角「系统 → 退出程序」可以关掉窗口。直接点窗口右上角的 × 也一样。

## 三、还能做什么

- 换单个状态：在右边某一行的下拉框里选别的素材，再到「系统」页点「启动这套」让改动生效。
- 加自己的素材：进「素材库」，上传图片（png/jpg/webp/bmp/gif）会自动生成 6 种尺寸的 .cur；也可以直接上传现成的 .cur / .ani / .ico。
- 改素材名字：素材库里鼠标移到素材上，点右上角的铅笔；或者双击名字。
- 调热点（指针的点击位置）：点素材图上的位置即可。
- 建多个套、导出分享包、导入别人给的包，都在界面上有对应按钮。

## 四、我的东西存在哪

```
%LOCALAPPDATA%\CursorKit
```

在这串地址前面加上「资源管理器」地址栏回车就能打开，或者点界面上「系统 → 打开数据目录」。

删掉这个文件夹等于恢复到刚安装的状态（素材和套会没，但不会影响系统里的光标文件）。

## 五、不想用了怎么办

1. 先在程序里点「停止」，把光标恢复成原来的样子。
2. 关掉窗口，删掉「光标套装管理器.exe」。
3. （可选）删掉上面第四条的 `%LOCALAPPDATA%\CursorKit` 文件夹。

程序不改动 `C:\Windows\Cursors` 里的任何文件，只改当前用户自己的光标设置，所以不会把系统弄坏。

## 六、打不开怎么办

本程序需要 64 位的 Windows 10（1803 及以上）或 Windows 11。

如果双击后什么都没发生，看这个文件里的错误信息：

```
%LOCALAPPDATA%\CursorKit\error.log
```

把它发给我，我能看出是哪一步出的问题。
